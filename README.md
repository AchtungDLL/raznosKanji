# raznosKanji
=======
# Осада

**Полное описание проекта — `PROJECT.md`.** Там цель, сеттинг, механики,
состав данных, этапы и то, чего мы сознательно не делаем. Читать первым.

Обучающая игра по японскому языку с русским интерфейсом. Повторение материала
встроено в игровой цикл: учебная единица — противник, ежедневные повторения —
осада укрепления.

Рабочее название. Уровень первой кампании — N4.

## Быстрый запуск

- Windows: двойной клик по `run.bat`
- Linux и macOS: `./run.sh`
- В облачной среде: `npm install && npm run dev` — поднимется на порту 3000

Локальный сервер обязателен: браузеры не грузят модули и JSON по протоколу
`file://`, поэтому двойной клик по `index.html` покажет пустой экран с ошибкой.

Проверка ядра: `npm test` (нужен Node 18 или новее).

## Стек — и почему именно такой

Чистый JavaScript, модули ES, типы через JSDoc. **React, TypeScript, Tailwind
и любые UI-библиотеки в проект не входят.** Это прототип на выброс: его задача
— получить базы, веса и баланс, а не дожить до релиза. Всё, что требует шага
сборки, тут только замедляет.

Vite стоит ровно для одного: чтобы облачные площадки видели рабочий dev-сервер
на порту 3000 и не пытались «починить» проект, переписав его на свой стек.
Транспиляции нет, исходники отдаются как есть.

## Данные

Получены из двух колод Anki конвертером `tools/convert_decks.py`.

- `words.json` — 1497 слов из Kaishi 1.5k Russian. Заполнение полное: русское
  значение, пример с переводом, фуригана, частотность.
- `kanji.json` — 2358 иероглифов из колоды на основе WaniKani.
- `links.json` — связь «иероглиф → слова, в которых он встречается».
- `report.json` — отчёт о полноте.

**Ловушка, о которой нужно знать.** Поле `kyu` — старая шкала японского
экзамена, до реформы 2010 года, где **4 самый лёгкий уровень, а 1 самый
трудный**. Поле `jlpt` — уже пересчёт в современную шкалу. Для кампании N4
нужны `jlpt === "N5"` и `jlpt === "N4"`, вместе 284 иероглифа. Фильтр по
`kyu === "4"` даст набор N5, и это обнаружится поздно.

Из этих 284 иероглифов русское значение есть у 185. Остальные 99 предстоит
перевести — это известная работа, а не сюрприз.

Звука в проекте нет по решению заказчика. Ссылки на аудиофайлы в данных
сохранены, сами файлы не приложены.

## Правила работы

Три исполнителя работают параллельно и видят друг друга только через
`src/core/types.js`. Отсюда правила:

1. **`types.js` и `balance.js` менять нельзя.** Не хватает поля — остановись
   и верни вопрос, не добавляй сам.
2. **Каждый работает только в своём каталоге.** Файл вне своей зоны —
   только на чтение.
3. **Числовые параметры обучения живут в `balance.js`.** Число, вписанное
   прямо в код модуля, считается дефектом.
4. **Не добавлять зависимости.** Проект запускается без установки чего-либо,
   и это требование, а не случайность.
5. **Не править тесты, чтобы они прошли.** Тест, мешающий коду, — повод
   вернуть вопрос.
6. **Готово — значит `npm test` зелёный и страница открывается.**

Подробности: `docs/03-conventions.md`. Обоснование решений по балансу:
`docs/balance-report.md` — там числа, а не мнения.
